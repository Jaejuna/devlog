# LLM Reasoning 원리와 과정

## 예상 카테고리\nAI / LLM 이론

## 다룰 내용 아이디어
- Reasoning이란 무엇인가 — 단순 다음 토큰 예측과의 차이
- Chain-of-Thought(CoT) — 생각을 단계별로 펼치는 원리
- Extended Thinking / Thinking Tokens — 내부적으로 무슨 일이 일어나는가
- RLHF에서 RLVR(Reinforcement Learning with Verifiable Rewards)로의 전환
- o1, o3, Claude 3.7, DeepSeek-R1 등 추론 모델 비교
- Reasoning이 잘 되는 문제 유형 vs 잘 안 되는 문제 유형
- 추론 토큰이 많아질수록 정확도가 올라가는 이유 (Test-Time Compute)
- Reasoning 모델의 한계 — 과도한 추론(overthinking), 환각
- 개발자 입장에서 Reasoning 모델을 언제 쓸지 판단하는 기준
