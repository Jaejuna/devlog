# LLM Temperature 매개변수의 변화와 미래

## 예상 카테고리
AI / LLM

## 다룰 내용 아이디어
- Temperature란 무엇인가 — 출력 다양성/무작위성 조절
- Temperature가 필요했던 이유 (창의성 vs 정확성 트레이드오프)
- 최신 모델들에서 temperature 효과가 줄어드는 이유
- 추론 모델(o1, o3, Claude 3.7 등)에서 temperature가 사라지는 배경
- 내부적으로 temperature를 대체하는 것 — extended thinking, chain-of-thought
- API에서 temperature 파라미터가 deprecated 되는 흐름
- 개발자 입장에서 달라지는 점 — 프롬프트 엔지니어링 전략 변화
- temperature 없이 창의성을 조절하는 방법
