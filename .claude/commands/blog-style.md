# 블로그 포스트 작성 스타일 가이드

## 줄 바꿈 규칙 (가장 중요)

**일반 단락은 반드시 `<br />`로 끝낸다.** Enter만으로 줄 바꿈하지 않는다.

```mdx
Claude Code를 개발 프로젝트에 투입할 때 가장 중요한 것은 **컨텍스트 관리**다.<br/>

목표는 단순하다 — **Claude가 지금 당장 필요한 정보만 보도록 유도하는 것.**
```

## `<br />` 사용 위치

- 일반 단락 끝 — 거의 모든 문단
- 닫는 섹션 직전 — `## 정리`, `## 퀴즈`, `## 마무리`, `## 면접 빈출 질문 요약`, `## 추천 선택 기준`, `## 정답 및 해설`
- `**실무에서는?**` 콜아웃 내부 — 첫 문장 뒤
- 중요 결과/하이라이트 라인 뒤 관련 노트가 이어질 때 — `<br /><br />`

## 프론트매터

```yaml
---
title: "제목"
date: "YYYY-MM-DD"
category: "카테고리"
tags: ["태그1", "태그2"]
excerpt: "한 줄 요약 — 검색/목록에 표시되는 설명"
readTime: 숫자
---
```

## 말투

**합쇼체(합니다/습니다)를 사용한다.** ~다, ~이다 체 사용 금지.

```mdx
❌ RTK는 CLI 명령어 출력을 필터링하는 프록시 도구다.
✅ RTK는 CLI 명령어 출력을 필터링하는 프록시 도구입니다.

❌ 설치 후 전역 hook을 설정한다.
✅ 설치 후 전역 hook을 설정합니다.
```

## 글 구조

- 도입부: 왜 이걸 알아야 하는지 1~2문장
- 인용구 있을 경우 `>` blockquote로
- 섹션 구분: `---`
- 개념 설명 → 예시/코드 → 실전 활용 순서
- 마지막 섹션: 표로 핵심 정리 (`## 정리`)

## 표 활용

개념 비교, 명령어 정리, 요약에 적극 사용한다.

```mdx
| 개념 | 설명 |
|---|---|
| 항목1 | 내용 |
```
